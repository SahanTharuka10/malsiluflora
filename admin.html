Connect your database

The site is still using the built-in bouquet list. Connect a free Supabase project to manage bouquets and photos from here.

  1. Create a free project at supabase.com.
  2. Open SQL Editor, paste supabase/setup.sql, change the email at the bottom to yours, then Run.
  3. In Authentication → Users, add a user with that email and a password.
  4. Copy the Project URL and publishable (anon) key into config.js.
  5. Reload this page, sign in and press Import bouquets.

Full steps are in supabase/README.md.
